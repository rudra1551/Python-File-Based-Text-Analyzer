# File-Based Text Analyzer (Python)

A command-line Text Analyzer built in Python that reads text from a file and provides detailed insights about its content.

This project focuses on applying core Python concepts to real-world input instead of just user-entered strings.

> Built while learning Python through hands-on projects.

---

## 🔹 Features

- Reads text from a `.txt` file
- Displays:
  - Total characters (with and without spaces)
  - Total number of words
  - Vowel count
  - Consonant count
  - Uppercase letter count
  - Lowercase letter count
  - Sentence count (based on line breaks)
- Word frequency analysis:
  - Displays most common words
  - User can choose top **N** frequent words
  - Option to show frequency of all words
- Clean, aligned, readable CLI output
- Safe handling of invalid file paths
- Input validation for numeric options

---

## 🔹 Concepts Used

- File handling in Python
- String manipulation
- Regular expressions (`re`)
- Dictionaries and `collections.Counter`
- Sorting and frequency analysis
- Modular programming
- Basic exception handling
- Input validation

---

## 🔹 How to Run

1. Clone the repository
2. Run the Python script
3. Enter the full path of a `.txt` file when prompted  
   (Forward slashes `/` are recommended on Windows)
4. Choose how many common words you want to display

---

## 🔹 Notes

- Sentence count is approximated using line breaks.
- The project prioritizes clarity, correctness, and learning over advanced NLP features.
